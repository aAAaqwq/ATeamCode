# Repository instructions

ATeam Code is in research and prototype planning.

## Current boundaries

- Do not claim runtime, sandbox, security, replay, rollback, or coding quality
  without matching executable evidence.
- Keep external harness behavior behind explicit adapters.
- Treat AGI Super Team manifests and Skills as versioned inputs, not runtime
  implementation.
- Prefer fail-closed behavior for missing permissions or capabilities.
- Do not commit credentials, tokens, transcripts containing secrets, or local
  machine paths.
- Publishing, releases, dependency additions, and destructive operations
  require explicit human approval.

## Evidence standard

Separate facts, inferences, and unknowns. Pin source versions for architecture
research and record exact commands and results for prototype claims.
